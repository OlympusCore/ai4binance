# AI4BINANCE EnterpriseAI vNext Reference Architecture

This directory contains the intentionally limited source material for the
AI4BINANCE public reference-architecture showcase. It demonstrates the
system's governance-first design without publishing the canonical research,
strategy, risk, decision, execution, operational, or runtime implementation.

The showcase is not a runnable trading system, a performance claim, or an
authorization to trade. It is provided for technical evaluation and
educational reference only. AI4BINANCE remains research-only; live orders are
blocked.

## What the showcase demonstrates

- A deterministic-first decision lifecycle.
- Evidence, validation, risk, and human-approval boundaries.
- A default-deny publication process with explicit allowlisting.
- The separation of architecture concepts from proprietary implementation.

## What the showcase does not include

- Trading strategies, parameters, signal fusion, scoring, or decision logic.
- Risk limits, position sizing, execution internals, or account configuration.
- Prompts, internal operating instructions, research, backtests, datasets, or
  runtime/audit artifacts.

The canonical repository is private. Each public export is built from an
explicit manifest, sanitized, secret-scanned, reviewed as a diff, and held for
human approval before any remote publication.
